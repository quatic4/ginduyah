# Ginduyah

A web-based Reddit story card generator that turns Reddit posts, comments, and replies into downloadable images for YouTube Shorts, TikTok, and Reels.

## Run locally

1. Install Node.js 22 or newer.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open `http://localhost:3000`.

## Deploy

Import this repository into Vercel as a Next.js project. Vercel will install the dependencies and build the site automatically.

Deployed with Vercel.
